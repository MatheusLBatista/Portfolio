Projects

Vilhena+Publica

Vilhena+Publica is a node API designed to improve communication between citizens and local government. It allows registered users to submit and track public service requests related to waste management, street lighting, sanitation, stray animals, and more. With an easy usage and role-based access control, the system ensures transparency, accountability, and efficiency in municipal services.

Enrollment Form

This project is a modern course enrollment form built with TypeScript, Zod for validation, and styled using HTML5 and CSS3. It features a clean interface plus light/dark mode support. Data is handled through a fake API using JSON Server, enabling create, read, and delete operations on registration records. The application was built with simplicity and responsiveness.

Mosquito Hunter Game

Mosquito Hunter is a fun and fast-paced browser game where players test their reflexes by clicking on mosquitoes that appear randomly on the screen. The game was designed to be simple, entertaining, and a great way to challenge your agility! Mosquitoes appear in random positions and sizes — your goal is to click on them before they disappear. Miss too many, and you lose! Choose your difficulty level and see how fast your reflexes really are.

Review Project

Linktree

This project is a fully customizable profile page inspired by Linktree, developed using HTML, TypeScript, and CSS. It dynamically renders user data based on the id parameter in the URL, fetching profile information from a data.json file. The goal was to build a flexible and modern alternative to Linktree, allowing full control over themes, profile images, link icons, and layout styling through CSS variables.
